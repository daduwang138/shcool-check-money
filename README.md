# 教学考勤记账本

给中小学老师自用的考勤 + 课时记账工具。出勤天数和课时数分开记、又能叠加算工资；数据全部留在自己电脑/手机上，不上传任何服务器。

两种形态，计算规则完全一致：

| 版本 | 位置 | 说明 |
|---|---|---|
| 电脑版 | `教学考勤记账本.html` | 单文件，双击用浏览器打开即用，无需安装、无需联网 |
| 小程序版 | `teaching-attendance-mp/` | 微信原生小程序，手机/电脑微信都能用，适合发给同事各自记账 |

## 功能

- **一天两个半天**：上午、下午分别记为 上班 / 加班 / 监考 / 请假 / 空。课时数与出勤独立填写，互不覆盖。
- **工资自动算**：`基本工资 ÷ 法定工作日 × 实际出勤天数 + Σ(各档课时数 × 该档单价)`，四舍五入到分。课时可以分档计价（正课 120、晚自习 80），也可以只用一档统一价。
- **法定日历内置，也能联网取**：内置 2026 年放假与调休表；新一年的安排公布后，电脑版「设置 → 放假安排 → 联网获取」直接抓国办发原文摘录，核对后一键写入；小程序端受域名备案限制不能联网，用「粘贴导入」接电脑版「复制给手机」生成的那一串。也能完全手动填，填了优先于内置。法定上班日默认勾选全天出勤，法定节假日不按课程表推算课时。
- **课程表推算课时**：按「星期几 + 第几周 + 单双周」配置课程，一键把整月课时填进日历；新学期前八周 / 后八周不同也能配。课程表可以从 Excel / WPS 直接粘贴导入，列顺序随意。
- **批量操作**：电脑版按住拖选；小程序版在日期上左右滑动、或按住约半秒，都会进入多选并连选（不必先点按钮），都能一次套用上班/监考/加班/请假/空，可只改上午或下午。连选默认只取工作日，周末与法定假日自动跳过，调休补班的周六日照常算；周末真要改，小节点一下补选，电脑版用「批量设置」勾周六日。误操作 5 秒内可撤销（也可点 × 立即关掉提示条）。
- **导出与核对单**：导出范围可选本月 / 近三个月 / 今年 / 全部，也能指定任意月份区间，文件里含月度汇总与每日明细；小程序同样四档，文件名带范围。汇总页还有「复制工资核对单」，一键把应发金额、扣哪几天、课时几节拼成一段话发给财务，两版文案由同一个函数拼出、逐字一致。
- **数据在自己手里**：电脑版可绑定一个本地文件夹，按 `年份/前缀_年-月.json` 分月存盘，改哪个月只重写那个文件；可选口令加密（PBKDF2 + AES-GCM）。小程序版可选口令锁（PBKDF2 派生校验值，设置与解锁都用密码输入框，切后台超 5 分钟自动重新上锁），锁的是「打开就要输」，数据本身仍明文存本机。
- **能转发给同事**：记账、汇总、设置、课程表、放假安排五个页面右上角「转发」都能用。发出去只是这个小程序本身，对方打开是自己的一份空库，不会带走你的账。

## 快速开始

**电脑版**：下载 `教学考勤记账本.html`，双击打开。第一次使用先在「设置」里填基本工资、课时单价、入职起算日，再配课程表。

**小程序版**：用微信开发者工具导入 `teaching-attendance-mp/` 目录即可预览；正式使用需要在微信公众平台注册小程序并上传代码。

## 目录结构

```
教学考勤记账本.html        电脑版（单文件，HTML + 原生 JS，离线可用）
功能逻辑.md                完整功能与规则说明（含边界情况与冲突裁决）
teaching-attendance-mp/    小程序版
  utils/core.js            纯函数内核：算出勤、算工资、法定日历、课程表
  utils/store.js           本地存储读写、导入导出
  utils/lock.js            口令锁：纯 JS SHA-256 / HMAC / PBKDF2，无依赖
  pages/calendar           记账页（月历）
  pages/summary            汇总页
  pages/settings           设置页
  pages/courses            课程表页（含粘贴导入）
  pages/holiday            放假安排页：自己补某年的休假与补班日，或粘贴电脑版抓到的安排
  pages/pass               设置/修改/关闭口令（密码输入框，不走明文弹窗）
  pages/lock               锁屏页（开了口令才用得到）
tests/                     校验脚本（Node 直接跑，无需依赖）
tools/                     预览构建与冒烟脚本（开发用，不参与小程序打包）
preview/                   生成好的单文件预览 mp-preview.html
```

## 测试

不需要安装任何依赖，装了 Node 就能跑：

```bash
node tests/verify_core.js      # 把 HTML 版和 core.js 并排跑，逐字段比对（38791 项）
node tests/test_pages.js       # 用桩模拟小程序运行时，跑页面逻辑（213 项）
node tests/check_structure.js  # 小程序 wxml/wxss 结构自检：标签闭合、事件方法、样式缺失
node tools/build_preview.js    # 生成单文件预览 preview/mp-preview.html，双击即可试交互
```

`verify_core.js` 会从 HTML 里切出原始算法，和小程序内核吃同一批数据比对结果——这是两版能保持一致的原因。

## 需要你手动做的

这两件代码替不了：

- **改完小程序要重传包**：`teaching-attendance-mp/` 的改动只在仓库里，手机上要生效得在应用卡「分享 → 更新」重新上传一次。
- **真机验收**：手势连选、滚动锁定、导出文件转「发送给聊天」这些，目前都在无头浏览器与预览里验证过，还差微信真机走一遍。
- **放假表跟着国务院走**：内置表只到 2026 年。新一年公布后不用改代码——电脑版「联网获取」抓到直接核对入库，小程序用「粘贴导入」接；也可以照学校校历手动填。想固化成内置默认值再补进 `HOLIDAYS`（两处要一起改，`verify_core.js` 会盯着）。

## 数据说明

- 电脑版默认存在浏览器 `localStorage`，绑定本地目录后以目录里的 JSON 文件为主数据。
- 小程序版存在 `wx.setStorageSync`，只在本机，换手机不会自动同步，需要手动导出/导入 JSON。
- 仓库里不含任何个人考勤数据。
