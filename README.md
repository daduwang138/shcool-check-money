# 考勤记账本-个人版

给中小学老师自用的考勤 + 课时记账工具。出勤天数和课时数分开记、又能叠加算工资；数据全部留在自己电脑/手机上，不上传任何服务器。

两种形态，计算规则完全一致：

| 版本 | 位置 | 说明 |
|---|---|---|
| 电脑版 | `教学考勤记账本.html` | 单文件，双击用浏览器打开即用，无需安装；只有主动点「联网获取」放假安排时才需要网络 |
| 小程序版 | `teaching-attendance-mp/` | 微信原生小程序，手机/电脑微信都能用，适合发给同事各自记账 |

> 微信里的小程序叫「考勤记账本-个人版」；电脑版磁盘文件名沿用 `教学考勤记账本.html`，只是本地文件名、不进微信包，改名会连累测试脚本路径，所以保留。

## 功能

- **一天两个半天**：上午、下午分别记为 上班 / 加班 / 监考 / 请假 / 空。课时数与出勤独立填写，互不覆盖。
- **工资自动算**：`基本工资 ÷ 法定工作日 × 实际出勤天数 + Σ(各档课时数 × 该档单价) + 晚修次数 × 每次金额`，四舍五入到分。课时可以分档计价（正课 120、晚自习 80），也可以只用一档统一价。
- **晚修监考单独记**：晚上监考**一晚就一场，一次 2 小时、10 元，定死的**——不算课时、不占出勤半天，也不按小时乘钱（拖到 3 小时还是 10 元），2 小时只写进核对单方便跟财务对时长。记账面板点一下记 1 次，一天只能记 1 次，误点不会多算；汇总里单列第 ④ 项，核对单与 CSV 都带这一笔。时长和金额在设置里留着给学校调口径，改过价不追溯改旧账；老备份读进来自动补上默认值。
- **账目一眼核对**：汇总页参数卡多了「其他档位」「晚修监考」两行只读价，不用来回切设置页；电脑版每日明细可勾「只看有课、晚修或有备注的日子」，快速筛出有争议的那几天。
- **法定日历内置，也能联网取**：内置 **2026、2027 两年**国办发放假与调休表（2027 依据国办发明电〔2026〕10号，除夕起连休 9 天）；往后新一年的安排公布后，电脑版「设置 → 放假安排 → 联网获取」直接抓国办发原文摘录，核对后一键写入；小程序端受域名备案限制不能联网，用「粘贴导入」接电脑版「复制给手机」生成的那一串。也能完全手动填，填了优先于内置。法定上班日默认勾选全天出勤，法定节假日不按课程表推算课时。
- **课程表推算课时**：按「星期几（可多选，一门课能排周一三五）+ 第几周 + 单双周」配置课程，一键把整月课时填进日历；新学期前八周 / 后八周不同也能配。课程表可以从 Excel / WPS 直接粘贴导入，列顺序随意。**默认还会自动落账**：进到本月就把「已经过去、课表上有课、又没手填过」的日子自动记上课时，最常见的「正常上班 + 有课」一天不用再点开面板；未来日期不预填、已手填或已核对的月份不动，10 秒内可撤销，设置里能一键关。
- **批量操作**：电脑版按住拖选；小程序版在日期上左右滑动、或按住约半秒，都会进入多选并连选（不必先点按钮），都能一次套用上班/监考/加班/请假/空，可只改上午或下午。连选默认只取工作日，周末与法定假日自动跳过，调休补班的周六日照常算；周末真要改，小节点一下补选，电脑版用「批量设置」勾周六日。误操作 10 秒内可撤销（也可点 × 立即关掉提示条）。
- **导出与核对单**：导出范围可选本月 / 近三个月 / 今年 / 全部，也能指定任意月份区间，文件里含月度汇总、每日明细，以及一张「各月实际采用的参数」表（跨月导出时能看出每个月按哪个冻结价算的）；小程序同样四档，文件名带范围。汇总页还有「复制工资核对单」，一键把应发金额、扣哪几天、课时几节拼成一段话发给财务，两版文案由同一个函数拼出、逐字一致。
- **数据在自己手里**：电脑版可绑定一个本地文件夹，按 `年份/前缀_年-月.json` 分月存盘，改哪个月只重写那个文件；可选口令加密（PBKDF2 + AES-GCM）。小程序版可选口令锁（PBKDF2 派生校验值，设置与解锁都用密码输入框，切后台超 5 分钟自动重新上锁），锁的是「打开就要输」，数据本身仍明文存本机。
- **能转发给同事**：记账、汇总、设置、课程表、放假安排五个页面右上角「转发」都能用。发出去只是这个小程序本身，对方打开是自己的一份空库，不会带走你的账。
- **少点几下**：两版记账面板都有「前一天 / 后一天」，连续补记一周不用关掉重开；电脑版弹窗多了「取消」，点遮罩也是放弃，误开一天不会在账本里留痕。只是打开看一眼就点「完成」，课程表的「用 N 节」提示还在，不会静默把这天记成 0 节。已核对的月份在一次打开里只问一次确认，不再补记一天点一次；撤销放宽到 10 秒，并连「已核对」标记一起还原。**课时这块省得最多**：「按课程表自动记课时」默认开，本月已过去、有课又没填过的日子进月自动记上，一学期少点约 300 次；未来的日子不预填，已核对的月份不动，10 秒可撤销（撤销后本月不再自动填），不想要就在设置里关掉。

## 快速开始

**电脑版**：下载 `教学考勤记账本.html`，双击打开。第一次使用先在「设置」里填基本工资、课时单价、入职起算日，再配课程表。晚修监考默认已填「一晚 1 次 · 2 小时 · 10 元」，平时不用动；学校标准真变了就在设置里改那两项。

**小程序版**：用微信开发者工具导入 `teaching-attendance-mp/` 目录即可预览；正式使用需要在微信公众平台注册小程序并上传代码。

## 测试

不需要安装任何依赖，装了 Node 就能跑：

```bash
node tests/run-all.js          # 一键跑全套（推荐，提交前跑这个）
```

`run-all.js` 依次跑六层，全部跑完才汇总，不会在第一个失败处停下：

| 层次 | 命令 | 覆盖 |
|---|---|---|
| 内核双版比对 | `node tests/verify_core.js` | 让 HTML 的转发层与 core.js 吃同一批数据逐字段比对（46725 项，含课程表自动落账、备注标签与本月事项），验证 `DB` 注入位置正确；另有「金额快照」用人工核算的期望值钉死算法本身，以及计薪项注册表、schema 迁移断言 |
| 页面逻辑 | `node tests/test_pages.js` | 用桩模拟小程序运行时，跑五个页面的方法（382 项，含「开关 × 冻结 × 空月份」7 组状态矩阵、DAY_FIELDS 逐字段合并冲突验证、设置默认值与本月冻结值的差异可见性与一键同步） |
| 结构自检 | `node tests/check_structure.js` | wxml 标签闭合、事件方法、wxss 花括号与 class 样式；**wxml 绑定契约**（94 个字段必须有 js 来源）、13 个动态 class、**SPEC / 转发层生成一致性护栏**、变异自检；外加两版文案哨兵（晚修填 0、应发公式、自动落账口径、冻结价说明、失焦提示） |
| 连构哈希 | `node tools/build_preview.js` ×2 | 连构两次产物逐字节一致 |
| 小程序预览冒烟 | `node tests/smoke_preview.js` | 真实浏览器点开预览页，走交互链路（30 条） |
| 电脑版浏览器冒烟 | `node tests/smoke_html.js` | 真实 DOM：设置改价 → 记账 → 汇总看钱，含冻价回看、误开取消、会话确认、课程表自动落账、2027 内置表与 CDN 空缓存换源（39 条） |

后两层需要本机有能跑 headless 的 Edge 或 Chrome。跑之前先拿一个极简本地页自检：浏览器找不到、或 `--dump-dom` 静默失效都标 `SKIP`（既不会假装通过，也不会把环境故障报成功能失败）；自检过了而真实页面拿不到探针结果，才算真失败。也可以用 `BROWSER=路径` 指定。生成预览单独跑：`node tools/build_preview.js`，产物 `preview/mp-preview.html` 双击即可试交互。

改了样式想先看一眼成什么样：`node tools/shot.js`（可以只截一页，如 `node tools/shot.js summary`）。它把预览页和电脑版各截一张 PNG 放到系统临时目录，电脑版那张会自动塞一份示例账，不然月历是空的看不出配色；要本机有 Edge / Chrome，产物不进仓库。生成前会先删掉同名旧 PNG，浏览器没产出时会**明确报错**，不会把上一次的图冒充本次结果（早期版本只查文件存在，headless 静默失效时会假成功）。

### 测试能证明什么（以及不能）

`verify_core.js` 的主力是「两版并排跑、逐字段比对」，它保证电脑版和小程序不会算得不一样，但**两版一样不等于算法对**。所以对有明确业务口径的地方另写了钉死期望值的断言：放假表解析、多档计价、冻结语义、晚修「2 小时 10 元/次」、CSV 逐月参数表、课程表自动落账（未来不填 / 已手填不覆盖 / 已核对不碰 / 关开关不写）、小程序专属辅助函数等。文件末尾还有一道**覆盖哨兵**：`core.js` 里新增函数若既没进比对切片、又不在白名单里，测试直接失败，不会出现「报表数字很大、其实新代码一行没测」。

这几套测试是随功能一起补的**回归保护**，不是严格的测试先行（红 → 绿 → 重构）；仓库也没有 CI，所以提交前请手动跑一次 `node tests/run-all.js`。浏览器冒烟脚本已经入库（早先放在被忽略的 `.tmp/`，换台机器就丢）。

### 覆盖边界：以前漏在哪，现在怎么拦

2026-11-14 之前反复出现「改完没反应」「提示里蹦出 undefined」「状态色点全透明」「放假日期默认 1/1」这类问题，根因不是某条用例写漏，而是测试只建模了**数据**，没建模**界面**和**状态组合**：

- `test_pages.js` 的桩只有 `setData`、不渲染 wxml → `data` 对了但界面错了，整类漏检；
- `check_structure.js` 原来只查「方法在不在、class 有没有样式、花括号配平」，267 个 `{{}}` 绑定、47 个 `wx:if` 一个都没校验，插值里的动态 class 还被整段抹成空格；
- `seedDb()` 只有「开关全开」一套默认值，没有交叉状态；
- 断言偏向「改了之后值对不对」，少有「不该变时没变」和「改完有没有给用户反馈」。

补上的三层都在 `run-all.js` 里，**不依赖浏览器**（浏览器层 SKIP 时照常工作）：

| 层 | 拦什么 | 当前覆盖 |
|---|---|---|
| 绑定契约 `orphanBindings()` | wxml 引用的字段 js 没写回；条件渲染字段停在初始值 | 94 个绑定字段；末尾带变异自检，故意漏写 `enableBase` 必须报错 |
| 动态 class 检查 | `{{on ? 'dim' : ''}}` 里的类名没在 wxss 定义 | 13 个动态 class |
| 状态矩阵 | 开关 × 已冻结/未冻结 × 空月份 | 7 组 × 5 项断言，含 toast 文案与 undefined / NaN |

约定：**每加一个用户可见的状态分支，先在矩阵里加一行**；每加一个 wxml 绑定，契约检查会自动确认它有来源。浏览器冒烟仍是唯一跑真实 DOM 的一层，长期 SKIP 不可接受，换 Chrome 或 `BROWSER=路径` 补跑。

### 双版同步怎么改（两步生成）

电脑版是**单文件、解压即用**，共享代码不能在运行时 `require`，只能构建时注入。两处都由生成工具负责，改完必须跑一次；漏跑由 `check_structure.js` 拦住，护栏自带变异自检。

| 改什么 | 唯一真源 | 生成命令 |
|---|---|---|
| 状态定义 / 放假表 / 计薪项注册表 / schema 字段清单 | `utils/spec.js` | `node tools/sync_spec.js` |
| 算法函数 | `utils/core.js` | `node tools/gen_core_adapter.js --write` |

改完统一跑 `node tests/run-all.js`。

**口径常量**：`STATES` / `CYCLE` / `HOLIDAYS` 曾经两版各抄一份，加个放假年份得改两处；现在改 `spec.js` 一处，`sync_spec.js` 生成电脑版的同名全局常量。

**计薪项注册表**：`PAY_ITEMS` 收在 `spec.js`，存四段式的标签、公式说明、CSV 列名。`computeMonth` 按它累加应发，核对单的 ①②③④ 和 CSV 金额列头都从它生成。加一个新计薪项只要「注册表加一行 + `computeMonth` 算出该金额 + UI 加一行显示」；漏算会被 `verify_core.js` 的「每项都有对应金额字段」「总额等于各项之和」拦住。

**算法函数**：HTML 里的手写算法实现已全部换成 `core.js` 的转发层。`tools/gen_core_adapter.js` 把 `core.js` 包成 IIFE 注入 HTML（挂到全局 `Core`），**只替换 60 个同名函数的函数体**，不动函数声明、参数、位置、注释，139 个 UI / 存储 / 联网函数原样保留。映射规则机械：36 个签名一致直接转发、21 个注入首参 `DB`、3 个（`isWorkday` / `autoWorkdays` / `isHoliday`）注入末参 `DB`。`verify_core.js` 的 `ctx.DB` 机制正好用来验证转发结果，46702 项逐字段比对从「证明两版手写一样」变成「证明转发层映射正确」。

小程序端 `core.js` 直接 `require('./spec.js')`；电脑版仍是单文件、无运行时依赖、解压即用，交付形态不变。

## 待办 / 规划

按「改一批 → 全套回归 → 提交」推进。**架构演进第 1～5 步已全部完成**；只剩浏览器安全网这一项环境限制。

- [x] **计薪项注册表（第 3 步）**：`PAY_ITEMS` 收进 `spec.js`，`computeMonth` 按它累加、核对单与 CSV 列头从它生成，配「金额快照」断言钉死算法本身。加一个计薪项从原来的 10+ 处降到「注册一行 + 算一个金额 + UI 加一行」。
- [x] **数据 schema / 状态写入收口（第 4～5 步）**：`spec.js` 加 `SCHEMA_VERSION` / `DAY_FIELDS` / `MIGRATIONS`，`migrate()` 由 `normalize()` 调用；因为 `store.save()` / `load()` 都过 normalize，**37 处写入调用点不用改**就自动获得迁移能力。`dayBody()` 从 `DAY_FIELDS` 派生，加日记录字段不会漏掉合并冲突判断。当前 v1 是初始版本、迁移表为空，数据格式逐字不变。
- [ ] **恢复浏览器安全网**：本机 Edge 157 与 Chrome 157 都能打印 `--version`，但 headless 的 `--dump-dom` / `--screenshot` / `--print-to-pdf` 全部 0 字节、stderr 空、exit 0；CDP 端口回环超时、`--remote-debugging-pipe` 零响应且浏览器进程立即退出。已排除：文件路径、启动参数（`--single-process` / `--headless=shell` / 窗口相关 feature）、代理环境变量、工具沙箱（非沙箱模式同样失败）、版本子目录二进制。**结论：这两个 Chromium 157 的 headless 渲染模式在当前会话里启动即退出**，不是输出被吞。
  - 已修的真实缺陷：`browser.js` 原来用 `filter(exists)[0]` 且 Edge 排在 Chrome 前面，装了 Chrome 也永远选不中。现在改为**逐个自检、选第一个真能跑 headless 的**，候选里 Chrome 优先并补了用户级安装路径。
  - 诊断命令：`node tools/probe_browser.js`（列出每个候选「在不在 / 能不能出 DOM」）。请在**自己的普通 PowerShell 终端**跑一次把输出贴回来：工具会话与交互会话可能不同，这是目前唯一还没验证过的变量。
  - 若交互终端也全部不可用，最终方案是装独立的 `chrome-headless-shell`（不创建隐藏窗口）后设 `BROWSER=路径`，或换台机器跑 `node tests/run-all.js`。`tools/shot.js` 已修掉「旧 PNG 冒充本次截图」的假成功，现在会明确报错。

以下两项也已列进规划，**本阶段不动实现**：

- [ ] **小程序端数据加密（规划中，数据格式先不动）**：现在只有口令锁（挡「随手点开」），考勤记录仍明文存在 `wx.setStorageSync`。要做真加密需要全库加解密与密钥派生、冷启动解锁流程、以及现有明文备份／导入的兼容迁移。前置问题是「口令一忘，数据就真的打不开了」，所以要先定备份与恢复策略，再动存储结构。当前阶段保持数据格式不变，避免升级后旧数据读不出来。

## 需要你手动做的

这几件代码替不了：

- **老备份升级后先看一眼自动落账**：新版本默认打开「按课程表自动记课时」，进到本月会把已过去、有课又没手填过的日子补上课时，并弹一条 10 秒撤销提示。不想要这个口径，先去设置里关掉开关；已记的账不会追溯删除。
- **改完小程序要重传包**：`teaching-attendance-mp/` 的改动只在仓库里，手机上要生效得在应用卡「分享 → 更新」重新上传一次。
- **真机验收**：手势连选、滚动锁定、导出文件转「发送给聊天」这些，目前都在无头浏览器与预览里验证过，还差微信真机走一遍。
- **放假表跟着国务院走**：内置 2026、2027 两年。2028 及以后公布时不用改代码——电脑版「联网获取」抓到直接核对入库，小程序用「粘贴导入」接；也可以照学校校历手动填。想固化成所有人开箱即用的内置默认值，只改 `utils/spec.js` 一处，再跑 `node tools/sync_spec.js`，两版同时生效（漏跑会被结构自检拦住）。

- 电脑版默认存在浏览器 `localStorage`，绑定本地目录后以目录里的 JSON 文件为主数据。
