# 考勤记账本-个人版

给中小学老师自用的考勤 + 课时记账工具。出勤与课时分开记、叠在一起算工资；数据全留在本机，不上传服务器。

两种形态，算法完全一致：

| 版本 | 位置 | 用法 |
|---|---|---|
| 电脑版 | `教学考勤记账本.html` | 双击用浏览器打开即用，无需安装 |
| 小程序版 | `teaching-attendance-mp/` | 微信开发者工具导入预览，或上传后手机使用 |

## 功能

- **上下半天分开记**：上午/下午各记上班、加班、监考、请假或空，课时单独填、互不覆盖。
- **工资自动算**：基本工资÷法定工作日×出勤 + 各档课时×单价 + 晚修次数×每次金额，到分。课时可多档计价。
- **晚修监考按次算**：每次 2 小时 10 元，不算课时也不占出勤；一晚最多记 2 次（点一次加 2 次），按次数×每次价算钱。
- **法定日历**：内置 2026、2027 放假调休；之后可在设置页联网获取（电脑版）或粘贴导入（小程序），也能手填。放假不排课、调休补班照常。
- **课程表自动落账**：配好星期几 + 起止周，整月课时一键填；默认还会把本月已过去、有课又没填过的日子自动记上，10 秒内可撤销，设置里可关。
- **年历总览**：一屏看全年 12 个月，标 ISO 周、教学周与节假日；点月份直接去那个月记账。右侧教学周需先在「设置 → 课程表与教学周」填开学那周的时间才显示。
- **年度统计**：汇总页切「年度」，按应发·总览 / 出勤 / 课时 / 晚修四个标签看全年，逐月横条一眼看出淡旺季；默认仍是当月。
- **批量与导出**：拖选（电脑版）或滑动/长按（小程序）连选多天一次套用；导出本月/近三月/今年/全部，或指定区间；「复制工资核对单」一段话发给财务，两版逐字一致。
- **数据在自己手里**：可选口令锁（小程序切后台 5 分钟自动上锁）；电脑版可绑定本地文件夹分月存 JSON，可选加密。转发给别人是各自一份空库，不带走你的账。

## 快速开始

电脑版：双击 `教学考勤记账本.html`，先在「设置」填基本工资、课时单价、入职起算日，再配课程表。

小程序版：微信开发者工具导入 `teaching-attendance-mp/` 预览；正式使用需注册小程序并上传。

改基本工资会同步当月（自然月）及以后已记账的月份，更早的月份保持原值；改课时单价仍只影响以后，已记账月份冻结当时价格。要单独改某个月，去汇总页「本月参数」。

## 数据说明

- 电脑版默认存浏览器 `localStorage`，绑定本地目录后以目录里的 JSON 为准。
- 小程序存 `wx.setStorageSync`，只在本机；换机需手动导出/导入 JSON。
- 仓库里不含任何个人考勤数据。

## 开发

```bash
node tests/run-all.js          # 六层回归，提交前跑
node tools/build_preview.js    # 重建小程序预览
node tools/shot.js summary     # 截图看效果
```

改 `utils/spec.js` 或 `utils/core.js` 后，必须分别跑 `node tools/sync_spec.js`、`node tools/gen_core_adapter.js --write` 再重建预览，漏跑会被结构自检拦住。规则细节见 `功能逻辑.md`，发布步骤见 `发布流程.md`。换机器先跑 `node tools/install_headless_shell.js` 装浏览器内核。
